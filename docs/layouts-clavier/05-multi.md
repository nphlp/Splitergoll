# 05. Profil multi

[Documentation](../README.md) › [Layouts clavier](../README.md#layouts-clavier) › 05. Profil multi

[← 04. Linux](04-linux.md) · [06. Profil auto →](06-auto.md)

`multi` démarre en Windows. Maintenir L1 et cliquer sur l’encodeur droit fait tourner le choix **Windows → Linux → macOS → Windows**. Le choix revient à Windows après redémarrage. La base, la navigation, les accents et L3 utilisent les adaptations ci-dessous selon l’OS.

Les schémas suivent les 15 couches de `multi`. `·` laisse passer l’action de la couche active inférieure. Dans une adaptation OS, cela signifie généralement reprendre l’action de la couche commune du même type. Les couches numérotées les plus hautes sont prioritaires. Le pavé et les couches de jeu sont partagés. La sortie du pavé et du jeu remet la base Windows.
