# Documentation Splitergoll

Splitergoll est un clavier ergonomique en deux moitiés, avec 42 touches, deux
encodeurs cliquables et un firmware ZMK. V1 est alimenté par USB. V2 a une
batterie par moitié et peut fonctionner en Bluetooth sur batterie.

- [Installer le firmware](developpement/2-compiler.md)
- Retrouver une touche sur [macOS](layouts/2-macos.md), [Windows](layouts/3-windows.md) ou [Linux](layouts/4-linux.md)
- [Connecter un ordinateur](utilisation/1-bluetooth.md) ou [vérifier les batteries](utilisation/2-batteries.md)
